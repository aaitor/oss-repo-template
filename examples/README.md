# Runnable examples

For a project generated from this template, add one folder per useful workflow. Each should include prerequisites, sample input, exact commands, expected output, and any cleanup steps. Use synthetic data and make costs explicit when external services are needed.

Run [the terminal demo](terminal-demo/README.md) to try customization in a temporary checkout. Follow the [recording tutorial](../docs/terminal-demo.md) to recreate the animation. The [quick start](../README.md#quick-start) shows how to create your own repository.
