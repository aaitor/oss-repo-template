# Banners, social cards, and demos

New README headers use the seven-style Claude Design kit from [aaitor/assets](https://github.com/aaitor/assets). The default is **diagonal-drift (1a)**: a dark Fog palette, diagonal line patterns, Instrument Serif title, and embedded Geist/Geist Mono fonts. The [banner generation guide](banner-generation.md) covers CLI and programmatic generation.

## Assets

- `assets/hero.svg`: 1280 × 320 README header generated by the bundled banner kit.
- `assets/example-hero.svg`: example header using the same default style.
- `banner-kit/`: generator, embedded fonts, upstream README, and font license notices. No npm packages or network access are needed.
- `assets/social-preview.svg`: separate 1280 × 640 social-card source using the original navy-and-mint renderer in `scripts/branding.py`.
- `assets/social-preview.png`: template social card. Setup removes this PNG so generated projects do not retain its identity.

Setup generates a new local hero with your title, tagline, and GitHub handle. It supports `--banner-style`, `--banner-seed`, and `--static-banner`. Keep titles at most 32 characters and taglines at most 60 for setup; preview longer text when using the kit directly, since it does not wrap or auto-fit. Check legibility at mobile width.

Original code and artwork use MIT. Embedded fonts remain under SIL OFL 1.1; retain the included [notices](../banner-kit/NOTICE.md), which are also embedded in generated SVGs.

## Export a personalized social card

The social card is a separate asset and retains the original navy-and-mint design. With CairoSVG installed in an isolated environment, run:

```bash
python3 -m venv .venv
.venv/bin/pip install cairosvg
.venv/bin/cairosvg assets/social-preview.svg -o assets/social-preview.png
```

Alternatively export with a vector editor. The PNG should be under 1 MB. Upload through **GitHub Settings → General → Social preview → Edit → Upload an image**. Committing an image does not configure the social preview; new repositories need their own setting. [GitHub recommends 1280 × 640](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Shared asset library

The template README uses a commit-pinned banner from [aaitor/assets](https://github.com/aaitor/assets). `shared-assets.json` records the source revision and copied files. Generated projects use local banners and a bundled generator, so they remain independent and work offline.

To update shared components, review the upstream changes, copy the selected kit/renderer/theme files with their license notices, update the manifest revision and pinned image URL, and regenerate affected assets. Setup does not download or execute remote code.
